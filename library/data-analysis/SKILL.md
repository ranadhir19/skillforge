# data-analysis

## Purpose

Answer questions from structured data with numbers that survive audit:
every figure looked up or computed by a tool, verified a second way,
and presented with its definition.

## Procedure

1. **Profile the data first.** What the table holds, its grain, its
   definitions (what "net" means here, which currency, which period).
   Analysis on an unprofiled table is astrology with spreadsheets.
2. **Look up, don't estimate.** Every base figure comes from the data
   tool. Derived figures come from the calculator over those lookups,
   with the expression shown.
3. **Verify each headline figure a second way** — a different
   aggregation path or a control total — and record the verification in
   the output, not in your head.
4. **Present values with definitions.** "Net revenue = revenue −
   costs, Q1 2026, USD" — a number without its scope is a rumour.
5. **Publish only through the gate.** Publishing a quantitative report
   requires human approval; the analysis itself never does.

## Rules

- If the data cannot answer the question, say so and stop — never fill
  the gap with a plausible figure.
- Round for display only; keep full precision in the working.
